# RoopSakhi – Vercel Demo

A responsive, static HTML/CSS/JavaScript prototype for the RoopSakhi at-home beauty marketplace.

## Deploy to Vercel
1. Extract this ZIP.
2. Create a GitHub repository and upload `index.html` and `vercel.json`.
3. In Vercel, choose **Add New → Project** and import that GitHub repository.
4. Framework Preset: **Other**.
5. Build Command: leave blank.
6. Output Directory: `.` (or leave the default for a static project).
7. Click **Deploy**.

You can also deploy using the Vercel CLI from this folder:
```bash
npx vercel
```

## Demo functionality
- Home, service catalogue, occasion packages and artist directory.
- Search/filter services and artists.
- Simulated booking form and confirmation.
- Professional registration interest form.
- Responsive mobile layout.

## Important
This is a front-end prototype. Sample artists, prices and ratings are illustrative. Bookings stay in browser memory and are not sent to a backend. No real OTP, payment, availability verification, artist onboarding, or database is connected. Do not accept real customer bookings until those systems and privacy/security controls are implemented.
